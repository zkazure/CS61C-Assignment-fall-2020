* Single-Cycle CPU

** Explain 
- *IF*: get *PC*, fetch instruction
- *ID*: generate control signals from instructions.
- *EX*: ALU calculation and do branch comparison. 
- *MEM*: get the memory address of destination register
- *WB*: write back
