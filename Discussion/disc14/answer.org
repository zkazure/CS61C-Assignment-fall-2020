* RAID
|        | Configuration    | Pro                      | Con                   |
|--------+------------------+--------------------------+-----------------------|
| RAID 0 |                  | fast read and write      | reliability           |
| RAID 1 | mirror           | fast read/write/recovery | storage               |
| RAID 2 | Humming ECC      | small overhead           | redundant check disks |
| RAID 3 | Byte-level strip | smallest overhead        | slow detect error     |
| RAID 4 | block-level      | higher throughput read   | slow write            |
| RAID 5 | distributed      | higher throughout write  | long time recovery    |
