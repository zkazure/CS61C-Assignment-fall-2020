* RISC-V with Arrays and Lists

1. arr[1] = arr[0] + arr[2]
2. each value plus 1
3. each value become negative

* RISC-V Calling Conventions

1. use a0, a1... (a0-a7)
2. a0, a1
3. stack pointer, used in prologue and epilogue
4. a0 (a0-a7, t0-t6 and ra)
5. nothing (sp, gp, tp, s0-s11)
6. sp, gp, tp, s0-s11 are guaranteed

* Writing RISC-V Functions

#+begin_src asm
  main:
      addi a0, x0, n
      jal ra, sumSquare
  sumSquare:
      addi sp, sp, -12
      sw ra, 0(sp)
      sw s0, 4(sp)
      sw s1, 8(sp)
      add s0, x0, a0
      add s1, x0, x0
  loop:
      beq s0, x0, end
      add a0, s0, x0
      jal ra, square
      add s0, s0, -1
      jal x0, loop
  end:
      add a0, x0, s1
      lw ra, 0(sp)
      lw s0, 4(sp)
      lw s1, 8(sp)
      addi sp, sp, 12
      ret
  square:
      mul a0, a0, a0
      ret
#+end_src
